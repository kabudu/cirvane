# ADR 0001: Cirvane product scope and claim boundary

- **Status:** accepted
- **Date:** 2026-08-24

## Context

The verified Nucleus v2 prototype requires an enduring name, independent private repository, product-grade identity and authenticated update path. A possible future novel kernel must not force another rebrand or inflate current claims.

## Decision

Use Cirvane as the maturity-neutral product identity. Ship the initial developer release on ESP-IDF/FreeRTOS after the rename, brand and authenticated OTA gates pass. Treat a clean-sheet kernel as an optional later research programme with its own ADR, prior-art study and matched evaluation.

## Consequences

Current performance and security evidence can be preserved with explicit historical provenance. Cirvane must not be called a novel kernel or production-ready. The name requires formal trademark review before public opening.

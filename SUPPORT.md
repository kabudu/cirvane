# Support

Cirvane is a pre-release engineering project, not a supported commercial device platform.

Use GitHub Issues for reproducible problems with the documented XIAO ESP32-C5 workflow. Include the commit, build profile, hardware revision, exact command and a redacted result. Questions about unsupported boards, production deployment, safety certification, custom ports or commercial support may be closed or redirected because no support commitment exists.

For vulnerabilities, use `SECURITY.md`. For contribution proposals, use `CONTRIBUTING.md`.

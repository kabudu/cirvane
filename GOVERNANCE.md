# Governance

Cirvane is currently maintainer-led. The repository owner, `@kabudu`, has final responsibility for scope, merges, release claims, security coordination, licensing decisions, brand use and repository visibility.

Technical decisions should be made in public issues and pull requests when they are not security-sensitive. Material architecture, trust-boundary, compatibility or release decisions require an ADR under `docs/DECISIONS/`. Evidence may disprove a proposal or narrow a claim; documentation alone cannot promote behaviour to implemented or verified.

Contributors gain no automatic commit, release or trademark authority. Maintainer roles may be added later with explicit scope. Conflicts of interest should be disclosed in the relevant issue or privately when disclosure itself is sensitive.

Only the repository owner may approve a version, tag, GitHub Release, binary publication, visibility change or use of the Cirvane identity outside the permissions granted by the software and asset licences.

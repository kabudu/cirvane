# Returning Facet depth studies

These studies retain F2's open recovery seam while adding depth without gradients, effects or embedded raster assets.

- **F2A: Folded Monolith** exposes each structural plane and makes the detached facet part of a larger material system.
- **F2B: Inset Aperture** keeps a strong outer silhouette while using inner faces to imply a machined recess.
- **F2C: Counterfold** emphasises overlapping bands and a visible recovery joint.

The colour version may use the approved mineral teal, aubergine, sea-glass and graphite. Every study must retain a coherent one-colour silhouette.

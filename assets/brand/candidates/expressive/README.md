# Expressive symbol round

This round responds to the owner's rejection of the first candidate set as too visually anonymous. The approved Quiet Horizon strategy and palette remain fixed, while the geometry introduces stronger mass, curves, counterforms and memorable silhouettes.

- **D: Vane Aperture** uses two asymmetric fields to create an observable central opening.
- **E: Recovery Fold** turns bounded transition into a substantial folded ribbon rather than a diagrammatic line.
- **F: Faceted Aperture** creates a compact boundary around a stable internal counterform.

These are decision candidates, not canonical marks. The first candidate set remains in the repository as rejected design evidence.

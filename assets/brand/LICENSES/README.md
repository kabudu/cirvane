# Brand asset licences and provenance

The Cirvane Recovery Scar dimensional symbol is an AI-assisted original project asset generated and selected under the owner's direction in 2026. The monochrome derivative, custom path-based wordmark, lockups, icons, templates and design tokens were produced for this repository from that approved identity. No third-party icon, embedded font or remotely linked resource is included. Repository distribution is under the MIT licence unless a future asset manifest records another licence; professional review of AI-assisted asset rights remains a public-opening gate.

The canonical wordmark is path-based and therefore has no font dependency. Product interfaces use platform system-font stacks; the repository redistributes no font files. Each operating system vendor's licence governs its locally installed system fonts.

The canonical dimensional source is the approved transparent extraction of the selected Recovery Scar concept. Its provenance and digest are recorded in the brand manifest. Earlier concept boards and rejected manual reconstructions remain design evidence only and are not shipped as canonical assets.

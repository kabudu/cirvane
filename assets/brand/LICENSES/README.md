# Brand asset licences and provenance

The Cirvane Recovery Scar symbol, custom path-based wordmark, lockups, icons, templates and design tokens are original project assets authored by OpenAI Codex under the owner's direction in 2026. They contain no traced raster artwork, third-party icons, embedded fonts or externally linked resources. They are distributed under the repository's MIT licence unless a future asset manifest explicitly records another licence.

The canonical wordmark is path-based and therefore has no font dependency. Product interfaces use platform system-font stacks; the repository redistributes no font files. Each operating system vendor's licence governs its locally installed system fonts.

AI image generation was used only for non-canonical concept exploration. The selected Recovery Scar concept was manually reconstructed as new deterministic SVG geometry. Generated concept images are not shipped brand assets.
